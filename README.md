# 军师 Chat

**帮你回她的恋爱聊天助手。** 把对方最新发来的话粘进来，给你三条**用你自己语气**写好的回复。
你自己填 API Key 直连 DeepSeek，聊天内容只在你和设备之间走。

## 这个项目的一条铁律

> **这是用户的恋爱，不是 AI 和对方的恋爱。**

所以 AI 只做一件事：写「我」要发出去的话。
**永远不扮演对方**、不替对方说话、不模拟对方会怎么回、不跟对方演对手戏。
对方的角色由现实中的人来演。

由此推出两条设计约束：

1. **目标是增进感情，不是「拿下」。** 不给操控手段——不用忽冷忽热、制造焦虑、嫉妒、
   愧疚或信息不对称来推进关系。那些短期可能有效，但会损害信任，最终伤害用户自己。
2. **语气只从「我」说过的话里学。** 不把对方的说话习惯混进候选里，
   否则用户会慢慢变得像对方，那是另一种走样。

融合来源：

- **骨架**来自 [jev-chat-jarvis](https://github.com/jev-chat/jev-chat-jarvis) /
  [jev-chat-windows](https://github.com/jev-chat/jev-chat-windows) 那条「聊天副驾」路线；
- **内核**来自 [goutoujunshi](https://github.com/shengjidaguai-china/goutoujunshi)（狗头军师）：
  先接情绪 → 再拆事实 → 最后给能执行的选择，外加 44 份心理／沟通／法律参考知识库。

## 一、给朋友的两个安装包

两个包都由 GitHub Actions 云端构建（`.github/workflows/build-installers.yml`），
你不需要装 Python、不需要 JDK、不需要命令行。

| 平台 | 文件 | 怎么用 |
| --- | --- | --- |
| Windows | `junshi-chat-windows.exe` | **双击**。程序会自己在后台起服务并打开默认浏览器，界面就出来了。 |
| Android | `junshi-chat-android.apk` | 传到手机上**点开安装**。系统提示「未知来源」时选允许（自签名包的正常提示）。 |

拿到手之后：

1. 打开界面 → 左下角（手机上是底部）点「**设置**」；
2. 在 **API Key** 里填入你自己的 DeepSeek Key，点「测试连接」确认通了，再「保存设置」；
3. 回到「**陪聊**」，直接开始说话。

> Key 只保存在你自己的设备上（exe 同级的 `data/config.json`，权限 600；手机上是应用私有目录）。
> 界面上永远只显示掩码，接口从不回显明文。

**这两个包怎么产出**：把仓库推到 GitHub，然后在 Actions 页面点一次「构建安装包」即可；
也可以本地推个 `v1.0.0` 标签，工作流会自动把两个包挂到 Release 上，你直接转链接给朋友。

## 二、四个页面在做什么

### 1. 回她（主功能）

把对方**刚发来的那句原话**粘进来，你会得到：

- **三条可以直接复制发送的成品**，用你自己的语气写的，策略上真有差异：
  - **接住** —— 先把对方的情绪或信息接稳，不加压、不提要求；
  - **推进** —— 在已有来有回的基础上往前走一小步（具体的关心、低压力邀约、真实的在意）；
  - **稳住** —— 降温、留白、给双方台阶，避免把话说死。
- 每条都标注**适合什么情况**和**发了可能有什么代价**。
- 一份**军师判断**（默认收起，不压过那三句话）：她的情绪与诉求、事实与推测、
  现在该做什么、**现在最不该说哪句**、接下来观察什么。

对话是连续的：她的原话和你实际发出去的话都会累积成上下文，记忆自然生长。

### 2. 记录分析

粘**一整段历史记录**进去，复盘关系走向：对方最新一条的真实意图（六选一）、
紧张度 0–10、建议动作、以及同样三条候选。

它和「回她」共用同一个引擎，区别只在输入：**回她解决「这句怎么回」，记录分析解决「这段关系怎么了」。**

### 3. 关系趋势（K 线）

按天聚合互动的**方向与力度**，支持粘贴或导入聊天 CSV。

口径公开、别误读：指数 = 当天净倾向 × 活跃度权重，滚动平滑后映射到 0–100。
只有一方说话的日子，沉默方按中性偏下计入；**完全断联的日子会明确压低，并且一定出现在曲线上**。
样本少于 12 条、跨度少于 4 天时会提示「只当参考」。

**它不代表感情好坏，更不是成功率。**

### 4. 记忆

**先明确同意，才开始保存。** 没开启时一个字节都不会写盘（这条有测试守着）。
开启后存两类东西，分工是刻意的：

| 类别 | 存什么 | 决定什么 |
| --- | --- | --- |
| **关系记忆** | 对方代号、MBTI、关系阶段、背景、边界／雷区、**关键事件** | 说什么 |
| **语气记忆** | **你真实发出去过的话**（以及你在「我平时怎么说话」里填的句子） | 怎么说 |

语气记忆有两条来源：你在档案页手动填的句子，以及你在候选上点「**我发的是这句**」——
后者让你确认实际发出的版本，越用越像你。取样按近因加权并限制字符预算，
最新的表达优先，同时不会把提示词撑爆。

随时可以撤销、单独删除某个对象、或一键清空全部。

## 三、自己跑源码

只需要 Python 3.10+，**不装任何第三方包**（整个项目只用标准库）。

```bash
# 桌面版：起服务并自动打开浏览器
./start-desktop.sh

# 移动版：手机上跑，打印要访问的地址
./start-mobile.sh

# 让同一 Wi-Fi 下的手机访问（注意：界面会暴露在局域网里）
./start-mobile.sh --lan
```

Windows 上是 `start-desktop.bat`（双击即可，会弹一个控制台窗口；不想看窗口就用上面那个 exe）。

自检与测试：

```bash
python3 -B main.py --check                          # 资源、知识库、存储门禁
python3 -B -m unittest discover -s tests            # 54 项后端测试
node --test tests/ui_smoke.test.mjs                 # 7 项前端测试
```

## 四、目录结构

```
junshi-chat/
├── junshi/
│   ├── core/
│   │   ├── api.py          DeepSeek 调用（标准库 urllib，密钥脱敏）
│   │   ├── engine.py       两条链路：回她 reply_to_her / 记录分析 analyze_chat
│   │   ├── persona.py      军师人设、身份声明与安全边界（SKILL.md 的可执行摘要）
│   │   └── parsing.py      模型输出的容错解析（JSON 坏了也不让整轮失败）
│   ├── kb/
│   │   ├── retriever.py    BM25 + 中文 bigram 检索，纯标准库
│   │   ├── SKILL.md        军师 skill 原文
│   │   └── references/     44 份参考文档（知识 20 + 实用 24）
│   ├── memory/profile.py   关系记忆 + 语气记忆 + 同意门禁（原子写入）
│   ├── trend/series.py     每日指数、CSV 解析、5 组示例走势
│   ├── server/app.py       HTTP 服务 + REST 接口 + 静态托管
│   └── paths.py            源码 / 冻结 exe 两种模式的路径解析
├── app/static/             响应式前端（一套代码，宽屏侧栏 / 窄屏底部标签）
├── packaging/
│   ├── windows/            PyInstaller 单文件 exe（launcher + spec）
│   ├── android/            Chaquopy 工程：把同一套 Python 引擎打进 APK
│   ├── sync_android_assets.{sh,ps1}
├── tests/                  后端 unittest + 前端 Node DOM 测试
└── .github/workflows/      云端构建 exe 与 apk
```

### 为什么桌面和手机共用一套代码

Android 包里用 [Chaquopy](https://chaquo.com/chaquopy/) 把**同一套 Python 引擎**打进去，
在 APK 内起一个只监听 `127.0.0.1` 的本地服务，WebView 加载同一套前端。

好处很直接：手机端和桌面端跑的是同一份、被同一批测试覆盖过的逻辑，不存在两个版本各自跑偏。
也正因为项目从头到尾只用标准库，Chaquopy 一个 pip 包都不用装，云端构建更不容易失败。

## 五、安全与边界

- **不读你的聊天软件**。没有无障碍服务、没有悬浮窗、没有 hook。记录要靠你粘贴或导入。
- **不替你发送**。所有回复都是草稿，发不发由你决定。
- **不诊断、不操控**。人设里明确禁止贬低、服从性测试、嫉妒操控、煤气灯、跟踪、性胁迫，
  也禁止用忽冷忽热、制造焦虑或愧疚来推进关系。遇到这类诉求它会拒绝并给合法替代。
- **不保证结果**。不承诺某句话能让某个人爱上你。对方明确表示不想发展、
  要求不要联系、或反复表示不欢迎时，它会让你停下来。
- **遇到家暴、跟踪、人身威胁**：先确认当下安全，联系可信支持或当地紧急服务
  （中国大陆可拨 110、12338）。
- **数据在你手里**：Key、档案、陪聊记录都在本机，卸载/删目录即清除。「清空全部数据」是真的清空。
